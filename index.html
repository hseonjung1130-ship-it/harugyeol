아이패드: Safari에서 이 사이트를 홈 화면에 추가한 뒤, 홈 화면의 하루결 앱에서 알림을 켜줘.

휴대폰 캘린더에 일정 추가

시험과 과제 마감 정보를 .ics 파일로 내려받아 캘린더에 가져올 수 있어. 실제 알림 제공은 캘린더 앱 설정에 따라 달라져.

푸시 알림은 서버가 배포되고 설정이 끝나야 작동해. 기존 ZIP을 단순 업로드하는 방식으로는 서버 기능이 설치되지 않아. 설치 방법은 함께 제공한 README 파일을 확인해 줘. 알림이 중요한 일정은 캘린더에도 등록해 두는 걸 추천해.
